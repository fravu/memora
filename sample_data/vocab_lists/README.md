# Beispiel-Vokabellisten (Deutsch → Englisch)

5 CSV-Dateien mit je 50 Wortpaaren, aufsteigend im Schwierigkeitsgrad — zum
manuellen Testen des CSV-Imports (`DeckDetailScreen` → Menü → "Aus CSV
importieren"). Format: `term,translation` mit Kopfzeile.

| Datei | Niveau | Thema |
|---|---|---|
| `lektion1_a1.csv` | A1 (Anfänger) | Alltagsgegenstände, Grundwortschatz |
| `lektion2_a2.csv` | A2 (Grundlagen) | Einkaufen, Wetter, Reisen |
| `lektion3_b1.csv` | B1 (Mittelstufe) | Meinungen, Entscheidungen, Gefühle |
| `lektion4_b2.csv` | B2 (Fortgeschritten) | Abstrakte/formale Begriffe |
| `lektion5_c1.csv` | C1 (Profi) | Akademisch/nuanciertes Vokabular |

Erfolgreich manuell auf einem physischen Android-Gerät importiert getestet
(2026-09-29).
